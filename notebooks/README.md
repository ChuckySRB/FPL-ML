# Notebooks

The notebooks document the academic workflow in reading order. Run commands from the repository root so paths resolve consistently.

1. `01_exploratory_data_analysis.ipynb` — raw-data quality, target distribution, positions, correlations, and season/gameweek trends.
2. `02_feature_engineering.ipynb` — leakage-safe rolling features, fixture context, imputation, and the temporal split.
3. `03_model_training.ipynb` — baseline and model experiments. Its final cell points to the canonical fixed-pipeline results.
4. `04_evaluation_and_error_analysis.ipynb` — executed final leaderboard, OpenFPL comparison, position/category results, feature importance, CV, and largest errors.
5. `05_app.ipynb` — legacy exploratory visualization. The maintained frontend is now `app.py`.

## Canonical workflow

Notebook cells are explanatory; the reproducible results are generated by scripts:

```powershell
python scripts/build_fixed_dataset.py
python scripts/run_academic_pipeline.py
python scripts/create_eda_figures.py
jupyter nbconvert --to notebook --execute --inplace notebooks/04_evaluation_and_error_analysis.ipynb
```

Training uses seasons 2020/21-2023/24 and tests on 2024/25. Do not fit transformations or models on the test season. The primary prospective window is GW32-38. Generated datasets, models, CSV results, and figures are ignored by Git and can be rebuilt with the commands above.
